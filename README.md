# Predictive Analytics Using Historical Data (Tableau)

## Project Overview

This project demonstrates predictive analytics using historical sales data in Tableau. The objective is to analyze past sales trends, identify seasonal patterns, and forecast future sales using Tableau's built-in forecasting capabilities.

## Objectives

* Clean and preprocess historical data
* Analyze sales trends over time
* Apply forecasting techniques using Tableau
* Visualize historical and predicted sales
* Support data-driven decision making

## Tools Used

* Tableau Public
* CSV Dataset
* Time Series Forecasting
* Trend Analysis

## Dataset

The dataset contains monthly sales records from 2021 to 2025.

### Fields

| Field | Description        |
| ----- | ------------------ |
| Date  | Monthly sales date |
| Sales | Sales amount       |

## Methodology

### 1. Data Preparation

* Imported CSV dataset into Tableau
* Verified data types
* Checked for missing values and duplicates
* Prepared data for analysis

### 2. Trend Analysis

* Created a line chart to visualize historical sales
* Applied trend line analysis to identify growth patterns

### 3. Forecasting

* Used Tableau's forecasting feature
* Analyzed historical sales data
* Generated future sales predictions
* Identified seasonal trends and business growth patterns

## Visualizations

### Sales Forecast

Displays:

* Historical Sales
* Forecasted Sales
* Future Trend Projection

### Sales Trend Analysis

Displays:

* Historical Trend
* Trend Line
* Overall Sales Growth Pattern

## Key Findings

* Sales exhibit an upward growth trend over time.
* Seasonal patterns are visible within the dataset.
* Forecast results indicate continued growth in future periods.
* Tableau forecasting provides valuable insights for business planning.

## Conclusion

This project successfully demonstrates the use of predictive analytics and time-series forecasting in Tableau. By analyzing historical sales data, future sales trends can be estimated, helping organizations make informed business decisions.
